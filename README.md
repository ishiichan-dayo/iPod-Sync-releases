# iPod Sync

iPod classic にドラッグ＆ドロップで曲を転送するデスクトップアプリ（Windows / macOS）の配布ページです。

## ダウンロード

[最新版のリリース](https://github.com/ishiichan-dayo/iPod-Sync-releases/releases/latest) から、お使いの OS 用のファイルをダウンロードしてください。

- **Windows**: `iPod.Sync_x.y.z_x64-setup.exe`
- **macOS**: `iPod.Sync_x.y.z_universal.dmg`（Intel / Apple Silicon 両対応）

一度インストールすれば、以降はアプリが起動時に新しいバージョンを確認し、ワンクリックで更新できます。

## 初回起動時の注意

- Windows: 「Windows によって PC が保護されました」と表示されたら「詳細情報」→「実行」
- macOS: Finder でアプリを右クリック →「開く」
